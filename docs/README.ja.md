# ✨ Nexus Hub — 日本語

[English](../README.md) · [🌍 Languages](../README.md#-languages)

無料・オープンソースの Roblox メニューです。公式版にキーは不要です。

## 🎮 機能

MM2：役職・プレイヤー ESP、銃の取得、自動射撃、殺人者向け機能、飛行、コイン収集。DOORS：ドア・鍵 ESP、警告、速度、回避。Blade Ball：パリィと ESP。汎用：ESP、移動、テレポート。

## 🧪 テスト状況

私たちの経験では MM2 は約99%、DOORS は約90%動作します。これは測定値ではなく推定です。自動射撃は命中を保証せず、動く相手を外すことがあります。前回のテストでは Blade Ball のパリィに問題があり、何度もゲームから退出させられたため新しいパリィ方式は未テストです。

## 🚀 使い始める

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/boranseasonnew/nexus-hub/main/dist/nexus-local-test.client.luau"))()
```
