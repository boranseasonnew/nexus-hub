# ✨ Nexus Hub — Bahasa Indonesia

[English](../README.md) · [🌍 Languages](../README.md#-languages)

Menu Roblox gratis dan sumber terbuka, tanpa kunci pada versi resmi.

## 🎮 Fitur

MM2: ESP peran dan pemain, mengambil senjata, auto shoot, fitur pembunuh, terbang dan koin. DOORS: ESP pintu dan kunci, peringatan, kecepatan dan menghindar. Blade Ball: opsi parry dan ESP. Universal: ESP, gerakan dan teleportasi.

## 🧪 Status pengujian

Menurut pengalaman kami MM2 berfungsi sekitar 99% dan DOORS sekitar 90%; ini perkiraan, bukan hasil pengukuran. Auto shoot tidak menjamin tembakan mengenai sasaran dan dapat meleset pada target bergerak. Parry Blade Ball bermasalah saat tes terakhir; sistem baru belum bisa diuji karena kami terus dikeluarkan dari permainan.
