# ✨ Nexus Hub — العربية

[English](../README.md) · [🌍 Languages](../README.md#-languages)

قائمة Roblox مجانية ومفتوحة المصدر، دون مفتاح في الإصدار الرسمي.

## 🎮 الميزات

MM2: إظهار الأدوار واللاعبين، جمع السلاح، إطلاق تلقائي، أدوات القاتل والطيران والعملات. DOORS: إظهار الأبواب والمفاتيح والتنبيهات والسرعة والمراوغة. Blade Ball: خيارات التصدي وESP. الوحدة العامة: ESP والحركة والانتقال.

## 🧪 حالة الاختبار

وفق تجربتنا يعمل MM2 بنسبة تقارب 99٪ وDOORS بنسبة 90٪؛ هذه تقديرات وليست قياسات. لا يضمن الإطلاق التلقائي الإصابة وقد يخطئ الأهداف المتحركة. واجه التصدي في Blade Ball مشاكل في الاختبار الأخير؛ ولم نتمكن من اختبار النظام الجديد بسبب الطرد المتكرر من اللعبة.
