# ✨ Nexus Hub — Polski

[English](../README.md) · [🌍 Languages](../README.md#-languages)

Darmowe menu Roblox o otwartym kodzie; oficjalna wersja nie wymaga klucza.

## 🎮 Funkcje

MM2: ESP ról i graczy, podnoszenie broni, automatyczne strzelanie, narzędzia mordercy, lot i monety. DOORS: ESP drzwi i kluczy, ostrzeżenia, szybkość i uniki. Blade Ball: opcje parowania i ESP. Uniwersalne: ESP, ruch i teleportacja.

## 🧪 Stan testów

Według naszego doświadczenia MM2 działa w około 99%, a DOORS w 90%; to szacunki, nie wyniki pomiarów. Automatyczny strzał nie gwarantuje trafienia i może chybić ruchomy cel. Parowanie Blade Ball sprawiało problemy w ostatnim teście; nowego systemu nie przetestowano z powodu ciągłego wyrzucania z gry.
