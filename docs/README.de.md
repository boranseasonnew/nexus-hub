# ✨ Nexus Hub — Deutsch

[English](../README.md) · [🌍 Languages](../README.md#-languages)

Kostenloses Open-Source-Roblox-Menü ohne Schlüssel in der offiziellen Version.

## 🎮 Funktionen

MM2: Rollen- und Spieler-ESP, Waffenaufnahme, Auto-Shoot, Mörderfunktionen, Flug und Münzen. DOORS: Türen- und Schlüssel-ESP, Warnungen, Geschwindigkeit und Ausweichen. Blade Ball: Parry- und ESP-Optionen. Universal: ESP, Bewegung und Teleport.

## 🧪 Teststand

MM2 funktioniert unserer Erfahrung nach zu etwa 99 %, DOORS zu etwa 90 %; dies sind keine Messwerte. Auto-Shoot garantiert keinen Treffer und kann bewegliche Ziele verfehlen. Das Blade-Ball-Parry war zuletzt fehlerhaft; das neue System konnte wegen wiederholter Spiel-Kicks nicht getestet werden.

## 🚀 Start

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/boranseasonnew/nexus-hub/main/dist/nexus-local-test.client.luau"))()
```

**Right Control** — menu.

## 🤝 Mitwirken und Community

Erstelle einen Fork und sende einen Pull Request. PRs für ein Schlüsselsystem in der offiziellen Version werden nicht angenommen. Nexus Hub hat keinen offiziellen Discord-Server.
