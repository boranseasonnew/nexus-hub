# ✨ Nexus Hub — 简体中文

[English](../README.md) · [🌍 Languages](../README.md#-languages)

免费、开源的 Roblox 菜单，官方版本无需密钥。

## 🎮 功能

MM2：角色与玩家透视、拾枪、自动射击、杀手功能、飞行和金币收集。DOORS：门和钥匙透视、实体提醒、加速与躲避。Blade Ball：格挡和透视选项。通用模块：透视、移动和传送。

## 🧪 测试状态

根据我们的使用经验，MM2 约有 99% 的功能可用，DOORS 约为 90%；这些是估计值，并非实测成功率。自动射击不保证命中，可能打不中移动目标。上次测试时 Blade Ball 格挡存在问题；由于不断被踢出游戏，新的格挡系统尚未得到测试。

## 🚀 开始使用

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/boranseasonnew/nexus-hub/main/dist/nexus-local-test.client.luau"))()
```

**Right Control** — menu.
