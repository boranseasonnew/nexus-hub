# ✨ Nexus Hub — Русский

[English](../README.md) · [🌍 Languages](../README.md#-languages)

Бесплатное меню Roblox с открытым исходным кодом; официальная версия не требует ключа.

## 🎮 Возможности

MM2: ESP ролей и игроков, подбор оружия, автострельба, функции убийцы, полёт и сбор монет. DOORS: ESP дверей и ключей, предупреждения, скорость и уклонение. Blade Ball: parry и ESP. Универсальный модуль: ESP, движение и телепорт.

## 🧪 Статус тестирования

По нашему опыту MM2 работает примерно на 99%, DOORS — на 90%; это оценки, а не измеренные показатели. Автострельба не гарантирует попадание и может промахиваться по движущимся целям. В последнем тесте parry Blade Ball работал с ошибками; новую систему не удалось проверить из-за постоянных киков.

## 🚀 Запуск

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/boranseasonnew/nexus-hub/main/dist/nexus-local-test.client.luau"))()
```

**Right Control** — menu.

## 🤝 Участие и сообщество

Создайте fork и отправьте pull request. PR с системой ключей в официальной версии не принимаются. У Nexus Hub нет официального Discord-сервера.
