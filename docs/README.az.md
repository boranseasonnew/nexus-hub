# ✨ Nexus Hub — Azərbaycanca

[English](../README.md) · [🌍 Languages](../README.md#-languages)

Pulsuz, açıq mənbəli və rəsmi versiyasında açar tələb etməyən Roblox menyusu.

## 🎮 Xüsusiyyətlər

MM2: rol/oyunçu ESP, silah toplama, avtomatik atəş, qatil alətləri, uçuş, noclip və coin toplama. DOORS: qapı/açar ESP, varlıq xəbərdarlığı, sürət və gizlənmə. Blade Ball: parry və ESP seçimləri. Universal modul: ESP, hərəkət və teleport.

## 🧪 Sınaq vəziyyəti

MM2 təxminən 99%, DOORS təxminən 90% işləyir; bunlar ölçülmüş göstərici deyil, təcrübəyə əsaslanan təxminlərdir. Avtomatik atəş vuruşa zəmanət vermir və hərəkətli hədəfləri qaçıra bilər. Son sınaqda Blade Ball parry problemli idi; oyundan davamlı çıxarıldığımız üçün yeni parry sistemi sınaqdan keçirilə bilmədi.
