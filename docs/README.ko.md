# ✨ Nexus Hub — 한국어

[English](../README.md) · [🌍 Languages](../README.md#-languages)

무료 오픈 소스 Roblox 메뉴이며 공식 버전에는 키가 필요하지 않습니다.

## 🎮 기능

MM2: 역할·플레이어 ESP, 총 획득, 자동 사격, 머더러 기능, 비행 및 코인 수집. DOORS: 문·열쇠 ESP, 경고, 속도 및 회피. Blade Ball: 패리와 ESP 옵션. 공통: ESP, 이동 및 텔레포트.

## 🧪 테스트 상태

경험상 MM2는 약 99%, DOORS는 약 90% 작동합니다. 이는 측정된 수치가 아닌 추정치입니다. 자동 사격은 명중을 보장하지 않으며 움직이는 대상을 놓칠 수 있습니다. 지난 테스트에서 Blade Ball 패리에 문제가 있었고, 계속 게임에서 추방되어 새 패리 시스템은 테스트하지 못했습니다.
